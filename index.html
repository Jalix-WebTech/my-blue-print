Learning philosophy

Four guiding principles

PRINCIPLE 01

Understand before implementing.

Never copy a pattern you cannot explain. Every technology on this roadmap is learned by understanding the problem it solves first, then the mechanics, then the implementation.

PRINCIPLE 02

Write code yourself.

AI is used primarily as a:

  • Tutor
  • Explainer
  • Reviewer
  • Debugging partner
  • Architecture discussion partner

— not as a replacement for learning.

PRINCIPLE 03

Build progressively.

Simple→Correct→Tested→Maintainable→Scalable

Do not introduce advanced architecture before it is necessary. Complexity must be earned by a real requirement.

PRINCIPLE 04

Lux Christi is the main project laboratory.

Every stage of learning eventually connects back to the real project. Practice exercises are chosen because they move Lux Christi closer to production quality.
